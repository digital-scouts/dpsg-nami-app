# Änderungen und Konflikte
{: .no_toc }

Mitglieder bearbeiten, auch ohne Netz. Parallele Änderungen führt die App automatisch zusammen.
{: .lead }

1. TOC
{:toc}

## Mitglied bearbeiten

1. In den Mitgliedsdetails auf den Stift tippen.
2. Name, Geschlecht, Geburtsdatum, E-Mails, Telefonnummern oder Adressen ändern <i class="ref">1</i>.
3. <span class="ui">Speichern</span> tippen. Es wird erst aktiv, wenn sich etwas geändert hat.
{: .steps }

Ob du bearbeiten darfst, entscheidet dein Recht in Hitobito. Ohne Schreibrecht fehlt der Stift.

## Ohne Netz

Klappt das Senden nicht, merkt die App die Änderung vor. Solange du die App nutzt, versucht sie es erneut, sobald Senden wieder erlaubt ist. In den Mitgliedsdetails sendet <span class="ui">Jetzt senden</span> sofort.

{: .wichtig }
Vor dem Abmelden versucht die App, offene Änderungen zu senden. Bleiben welche übrig, fragt sie nach, bevor sie verloren gehen.

## Zusammenführen und Problemlösung

Hat jemand dieselbe Person inzwischen im Web geändert, vergleicht die App Feld für Feld. Geänderte Felder auf beiden Seiten führt sie zusammen, solange sie verschieden sind. Du merkst davon nichts.

Nur wenn dasselbe Feld auf beiden Seiten unterschiedlich geändert wurde, entsteht eine Problemlösung <i class="ref">2</i>:

1. Die App zeigt den Fall in den Einstellungen, in den Mitgliedsdetails und in der Mitgliederliste.
2. Je Feld <span class="ui">Lokal behalten</span> oder <span class="ui">Serverwert verwenden</span> wählen. Über <span class="ui">Bearbeiten</span> lässt sich der Wert auch neu eingeben.
3. <span class="ui">Speichern</span> sendet den Stand erneut.
{: .steps }

Schließt du die Seite vorher, bleibt der Fall offen. Wie die App genau vergleicht, steht unter [Technik → Zusammenführung](../../technik/zusammenfuehrung/).
