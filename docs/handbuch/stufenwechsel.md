# Stufenwechsel
{: .no_toc }

Die App zeigt, wer zum nächsten Stichtag in die nächste Stufe wechselt.
{: .lead }

1. TOC
{:toc}

## Empfehlung lesen

Der Tab <span class="ui">Stufenwechsel</span> listet je Stufe, wer zum Stichtag die Altersgrenze erreicht <i class="ref">1</i>. Das Alter steht in Jahren und Monaten, die Spalte <span class="ui">Wechsel</span> zeigt die Zielstufe.

In den Mitgliedsdetails steht im Tab <span class="ui">Rollen</span> bei Kindern und Jugendlichen ohne Leitungsrolle der nächste Wechsel: jetzt, ab einem Jahr oder bis zu einem Jahr <i class="ref">2</i>.

## Stichtag und Altersgrenzen anpassen

1. Einstellungen → <span class="ui">Stammeseinstellungen</span> öffnen <i class="ref">3</i>.
2. Unter <span class="ui">Stufenwechsel</span> das <span class="ui">Datum</span> für den nächsten Wechsel wählen.
3. Die Altersgrenzen je Stufe so einstellen, wie euer Stamm wechselt, und speichern.
{: .steps }

Ohne Stichtag rechnet die App nicht. Die Einstellungen gelten nur auf diesem Gerät.

{: .hinweis }
Die App schlägt Wechsel nur vor. Die neue Rolle legst du wie gewohnt in der NaMi im Web an. Beim nächsten Sync zeigt die App den neuen Stand.
