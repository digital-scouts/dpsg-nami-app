# Arbeitskontext wechseln
{: .no_toc }

Die App arbeitet immer in genau einer Ebene, meist deinem Stamm. Wer Rechte auf mehreren Ebenen hat, wechselt bewusst.
{: .lead }

## Was der Arbeitskontext ist

Ein Arbeitskontext ist eine Ebene aus der NaMi, etwa ein Stamm, ein Bezirk oder eine Diözese. Mitgliederliste, Suche, Statistik und Stufenwechsel zeigen nur diese Ebene. Gruppen wie eine Meute oder ein Trupp sind darin Filter, keine eigenen Kontexte.

Beim ersten Start wählt die App die Ebene, in der du deine Hauptrolle hast.

## Wechseln

1. Profil öffnen.
2. Unter <span class="ui">Arbeitskontext</span> auf <span class="ui">Layer wechseln</span> tippen <i class="ref">1</i>.
3. Die gewünschte Ebene wählen. Die App lädt deren Daten neu.
{: .steps }

{: .wichtig }
Offline verfügbar ist immer nur der aktive Arbeitskontext. Nach einem Wechsel ersetzt die App die gespeicherten Daten, deshalb braucht der Wechsel Netz.

## Welche Ebenen angeboten werden

Die Liste enthält nur Ebenen, in denen du mit einer eigenen Rolle lesen oder schreiben darfst. Unterebenen gehören nicht automatisch dazu: Ein Bezirksvorstand sieht seine Stämme erst nach einem Wechsel in den jeweiligen Stamm. Die genauen Regeln stehen unter [Technik → Arbeitskontextmodell](../../technik/arbeitskontext/).
