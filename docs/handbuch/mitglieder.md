# Mitglieder
{: .no_toc }

Suchen, filtern, sortieren und alles Wichtige zu einer Person auf einen Blick.
{: .lead }

1. TOC
{:toc}

## Suchen und filtern

Der Tab <span class="ui">Mitglieder</span> zeigt alle Personen deines [Arbeitskontexts](../arbeitskontext/) <i class="ref">1</i>.

- **Suche:** findet Personen nach Name, E-Mail oder Mitgliedsnummer.
- **Gruppen-Chips:** Unter der Suche steht je Meute, Trupp oder Runde aus Hitobito ein Chip. Mehrere Chips zeigen alle Personen, die in mindestens einer der Gruppen sind.
- **Aktualisieren:** Liste nach unten ziehen.

{% include shots.html items="mitglieder:Mitgliederliste mit Gruppen-Chips|mitgliedsdetail:Mitgliedsdetails" %}

## Sortieren und Zusatztext

1. Rechts in der Suche <span class="ui">Filtern und sortieren</span> tippen.
2. Unter <span class="ui">Sortiere nach</span> Name, Vorname, Alter, Stufe oder Mitgliedsdauer wählen.
3. Unter <span class="ui">Zusatztext</span> festlegen, was unter dem Namen steht: Mitgliedsnummer, Fahrtenname, Geburtstag oder Eintrittsdatum.
4. <span class="ui">Anwenden</span> tippen.
{: .steps }

Weicht die Einstellung vom Standard ab, ist das Symbol in der Suche markiert. <span class="ui">Zurücksetzen</span> stellt den Standard wieder her.

## Eigene Gruppen

Reichen die Gruppen aus Hitobito nicht, baust du dir eigene aus Regeln, etwa „alle Leitenden im Trupp Kompass“.

1. <span class="ui">Filtern und sortieren</span> öffnen und <span class="ui">Filtergruppe erstellen</span> tippen.
2. Namen und optional ein Icon vergeben.
3. Regeln hinzufügen: Gruppe und Rolle wählen, dazu <span class="ui">Hat</span> oder <span class="ui">Hat nicht</span>.
4. Bei mehreren Regeln die <span class="ui">Verknüpfung</span> wählen: <span class="ui">UND</span> verlangt alle Regeln, <span class="ui">ODER</span> eine davon.
5. Speichern und <span class="ui">Anwenden</span> tippen.
{: .steps }

Aktive eigene Gruppen erscheinen als Chip neben den Gruppen aus Hitobito. Der Schalter blendet eine Gruppe aus, ohne sie zu löschen. Eigene Gruppen gelten nur auf diesem Gerät. Die Statistik zählt eigene Kacheln nach denselben Regeln, siehe [Statistik](../statistik/).

## Mitgliedsdetails

Ein Tipp auf eine Person öffnet die Details <i class="ref">2</i>:

| Tab | Inhalt |
|:--|:--|
| <span class="ui">Daten</span> | Kontakt, Adresse, Familie im Stamm und weitere Angaben. Telefonnummer oder E-Mail antippen, um anzurufen oder zu schreiben. |
| <span class="ui">Rollen</span> | Rollenverlauf und der nächste [Stufenwechsel](../stufenwechsel/) |
| <span class="ui">Qualifikationen</span> | Führungszeugnis, Prävention und Erste Hilfe, siehe [Qualifikationen](../qualifikationen/) |

Mit Bearbeitungsrecht öffnet der Stift oben rechts das Bearbeiten, siehe [Änderungen und Konflikte](../aenderungen/).

{: .hinweis }
Was die App zeigt, hängt von deinen Rechten in Hitobito ab. Fehlt dir eine Person oder ein Feld, hilft die [FAQ](../faq/).
