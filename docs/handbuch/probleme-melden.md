# Probleme melden
{: .no_toc }

Fehler, Wünsche oder Lob: so erreichst du den Entwickler.
{: .lead }

## Hilfe & Diagnose

Einstellungen → <span class="ui">Hilfe & Diagnose</span> bündelt alles, was bei Problemen hilft <i class="ref">1</i>. Die Seite ist auch ohne Anmeldung erreichbar.

| Eintrag | Wozu |
|:--|:--|
| Problem melden | Fehlerbericht per E-Mail mit App-Protokoll |
| Daten jetzt aktualisieren | Sync sofort starten |
| Protokolle | App- und Netzwerkprotokoll ansehen und teilen |
| Feedback senden | Idee, Lob oder Fehler direkt aus der App |
| Speicher freigeben | Karten-Cache löschen oder die App zurücksetzen |

{% include shots.html items="hilfe:Hilfe & Diagnose|problem_melden:Problem melden" %}

## Problem melden

1. In <span class="ui">Hilfe & Diagnose</span> auf <span class="ui">Problem melden</span> tippen.
2. Bereich wählen und kurz beschreiben: Was hast du gemacht, was ist passiert, was hast du erwartet <i class="ref">2</i>?
3. <span class="ui">Weiter zur Mail</span> öffnet dein Mailprogramm. Das App-Protokoll der letzten 24 Stunden hängt an.
{: .steps }

Du siehst Empfänger und Anhänge, bevor du sendest. Die Protokolle enthalten keine Inhalte von Anfragen, aber technische IDs von Personen und Gruppen.

## Feedback senden

<span class="ui">Feedback senden</span> öffnet ein Formular für Text und auf Wunsch Screenshots. Es geht an den Dienst Wiredash.

{: .achtung }
Achte darauf, dass auf Screenshots keine Mitgliederdaten zu sehen sind, oder übermale sie vor dem Senden.
